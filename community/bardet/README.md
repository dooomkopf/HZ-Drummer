# R.P. Bardet: 260 Drum Machine Patterns (Hydrogen-Fassung)

421 Bausteine in 22 Stilen von Rock und Funk über Latin und Reggae bis zu Tänzen: die Grundmuster und Breaks
als Ein-Takter, dazu Vier-Takter (dreimal das Muster, dann der Break mit demselben Feel).

- **Quelle:** die Hydrogen-Fassung von Albert Phelipot im
  [Hydrogen Song-and-pattern-repository](https://github.com/hydrogen-music/Song-and-pattern-repository), nach
  dem Buch „260 Drum Machine Patterns“ von René-Pierre Bardet (Hal Leonard).
- **Lizenz:** [CC BY-SA](https://creativecommons.org/licenses/by-sa/4.0/), wie die Hydrogen-Fassung; diese
  Bausteine stehen unter derselben Lizenz. Namensnennung: „R.P. Bardet, Hydrogen-Fassung von Albert Phelipot“.
- **Geändert:** ins Pattern-Format von HZ-Drummer übertragen, Vier-Takter ergänzt. Jeder Baustein nennt seine
  Hydrogen-Datei im Feld `origin`.
- **Umwandler:** [tools/import/hydrogen/h2import.py](../../tools/import/hydrogen/h2import.py)

Kennungen `user.bardet-…`.
